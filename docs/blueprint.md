# **App Name**: UniAssist Hub

## Core Features:

- Dynamic Hero Section: Displays the project title, subtitle, and a prominent 'Conocer proyecto' button on a dark, animated background.
- Problem Statement Display: Presents the detailed problem statement as plain text within a well-defined section.
- General Objective Card: Highlights the main general objective in a visually distinct, highlighted card-like block.
- Specific Objectives Section: Showcases specific objectives as interactive cards, each with an appropriate technological icon.
- Justification Text Block: Displays the project justification, focusing on its value proposition.
- Responsive Design Engine: Ensures the entire landing page adapts seamlessly for optimal viewing on both mobile and desktop devices.
- AI-Powered Executive Summary Tool: An AI tool to dynamically generate concise and compelling executive summaries for project sections (e.g., Problem Statement, Justification) for various target audiences, streamlining content presentation.

## Style Guidelines:

- Primary highlight color: Vibrant red (#FF1E2D) to draw attention and denote action. Used for main buttons and key titles.
- Background color: Deep dark grey (#2B2B2B) for a modern, sophisticated, and technological base, adhering to a dark color scheme.
- Accent color: Darker red (#A30000), used for subtle gradient effects, secondary highlights, or internal dividers, providing depth to the red theme.
- Text color: Pure white (#FFFFFF) for maximum contrast and readability against the dark background.
- Headline and body font: 'Inter' (sans-serif) for its modern, clean, and versatile appearance, suitable for bold, uppercase titles and legible body text. Features ample letter spacing for a corporate feel.
- Use sleek, modern technology-themed icons (e.g., AI, camera, data representation) for specific objective cards to enhance visual appeal and thematic relevance.
- Adhere to a minimal, elegant layout with clear visual hierarchy, ample spacing between sections, and responsive design for all screen sizes. Elements like cards will feature shadows and rounded borders.
- Incorporate smooth transitions for scroll, hover states, and element fades. Buttons will include subtle glow or red gradient effects on interaction, and the hero section will feature soft background animation. A 'tech' red lighting effect will be used for emphasis.
